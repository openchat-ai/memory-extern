# 07_phy_digital — 数字 PHY 设计

## 目标

设计一个"尽量数字化"的 LPDDR5X PHY，利用 foundry 提供的 I/O cell，把模拟部分最小化。

## 架构

```
数字 PHY 架构：
┌─────────────────────────────────────────────┐
│                 数字 PHY                     │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐     │
│  │ TX 数字  │  │ RX 数字  │  │ 时钟管理 │     │
│  │ PISO    │  │ SIPO    │  │ DLL     │     │
│  └─────────┘  └─────────┘  └─────────┘     │
│       ↓            ↓            ↓           │
│  ┌─────────────────────────────────────┐    │
│  │          I/O Cell (Foundry)         │    │
│  │    驱动器 + 接收器 + 终端匹配       │    │
│  └─────────────────────────────────────┘    │
│                     ↓                       │
│                 引脚连接到 DRAM              │
└─────────────────────────────────────────────┘
```

## 已完成的 RTL 模块

### 1. `piso.v` — TX 通路（发送）
- **功能**：并串转换，将并行数据转换为串行输出
- **参数**：WIDTH（并行宽度）、DEPTH（流水级数）
- **接口**：clk, rst_n, load, din, dout, ready
- **状态**：加载并行数据 → 移位输出 → 就绪

### 2. `sipo.v` — RX 通路（接收）
- **功能**：串并转换，将串行数据转换为并行输出
- **参数**：WIDTH（并行宽度）
- **接口**：clk, rst_n, din, bit_clk, dout, valid
- **状态**：采样串行数据 → 移位累加 → 输出有效

### 3. `dll.v` — 时钟管理
- **功能**：数字延迟锁定环，生成多相时钟
- **参数**：PHASES（时钟相位数）、TAP_BITS（延迟抽头位数）
- **接口**：clk_in, rst_n, enable, clk_out, locked
- **状态**：IDLE → SEARCH → LOCKED

### 4. `dphy_top.v` — 顶层模块
- **功能**：集成 TX/RX 通路和时钟管理
- **参数**：DQ_WIDTH（数据宽度）、CA_WIDTH（命令地址宽度）、PHASES（时钟相位数）
- **接口**：
  - 控制器接口：tx_din, tx_valid, tx_ready, rx_dout, rx_valid
  - DRAM 接口：dq_out, dq_in, dq_oe, ck_p, ck_n, ca, cke, cs_n, ras_n, cas_n, we_n
- **生成逻辑**：8 个 PISO（TX）+ 8 个 SIPO（RX）

### 5. `dphy_tb.v` — 测试平台
- **测试内容**：
  - TX 基本功能
  - RX 基本功能
  - 时钟输出验证
- **波形输出**：dphy_tb.vcd

## 关键设计决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 驱动器 | Foundry I/O Cell | 不用自己设计模拟电路 |
| DLL | 数字实现 | 避免模拟 PLL |
| 均衡 | 数字滤波器 | 可编程，灵活 |
| 串并转换 | 纯数字 | 标准数字逻辑 |

## 与传统 PHY 的区别

| | 传统 PHY | 数字 PHY |
|---|---|---|
| 驱动器 | 自己设计 | 用 foundry cell |
| 接收器 | 自己设计 | 用 foundry cell |
| DLL | 模拟 | 数字 |
| 均衡 | 模拟 | 数字滤波器 |
| 你需要设计 | 全部 | 只要数字部分 |
