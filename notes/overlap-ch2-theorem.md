# 第 2 章 定理

## 2.1 定义

设存储层次由 N 层介质构成，按单次字节访问代价单调上升排序：
M₁（最慢，代价最高）→ M₂ → … → M_N（最快，代价最低）。

对数据项 d，被访问（复用）总次数 R ≥ 1。
记 Rᵢ = d 从介质 Mᵢ 被读取的次数（i = 1 … k，M₁ 最慢）。

**参与路径**：定理只对 d 实际穿越的介质下结论。若某介质物理上更快、但 d 从不进入它（如板上的 SDRAM，数据不进或仅局部进入），它不在 d 的参与路径上，不进求和范围。

## 2.2 定理

**定理 2.1（慢介质读一次）**：设数据项 d 被复用 R ≥ 1 次，且复用实际发生在 d 能到达的最快介质 M_k 上。则对任意 i < k，恒有

    Rᵢ ≥ 1

且该下界**同时可达**：存在一个读取调度，使 Rᵢ = 1 对所有 i < k 同时成立，且其余 R−1 次全部落在 M_k 上。

**推论**：若复用发生在最高速层 M_k，则慢层总和的最小值为恰好在每层各读一次；使该最小值达成的调度同时是慢访问代价最小的调度。

## 2.3 证明

三步。

**1. 信息守恒下界（无条件）**：d 若从未被从 Mᵢ（i < k）读入，则 d 不可能到达 M_{i+1} 及以上层次，更不可能到达 M_k 被复用——数据只能逐层向上搬移，不存在跳过 Mᵢ 进入更高层的通路。因此每层 Mᵢ（i < k）至少被读一次：Rᵢ ≥ 1。此下界不依赖容量、不依赖任何具体工作量。∎

**2. 代价单调**：介质按访问代价单调排序，i 越大代价越低。任何"多余的"慢读（即越过下界 1 的额外次数）都可被替换为一次快读而不增加总代价，因为慢读严格贵于快读。故达到下界（每慢层恰好一次）的调度使慢访问代价最小。∎

**3. 可达性**：复用发生在 M_k 上，意味着 d 在 M_k 上有活集位置，R−1 次复用可全部在 M_k 内完成。d 到达 M_k 的路径即逐层各读一次（M₁ 一次 → M₂ 一次 → … → M_k）。该调度合法且同时满足所有下界。∎

## 2.4 边界

- **容量**：容量不构成定理的条件。定理不要求高层放得下，只要求复用事实存在——即 d 确实在 M_k 上被复用。若活集超出 M_k 容量，复用无法全部发生在 M_k，数据要么在更窄层内做局部复用（liveness 驱逐），要么被重读——这是定理**不在场**的情形（假设不成立），定理不被违反。容量只划定适用范围，不否定定理。
- **不参与介质**：物理更快但数据从不进入的介质不在求和范围，其速度无关。

## 2.5 文献对账

- **Eyeriss**（Chen 等，ISCA 2016）：row-stationary 数据流，AlexNet 上 DRAM 访问 0.0029 次/MAC，即每个权重字节从 DRAM 读一次、片上复用约 344 次。慢介质读一次、最快层复用的实证存在性实例。
- **Roofline**（Williams 等，CACM 2009；vLLM 技术报告）：带宽受限区（decode，~1 FLOP/byte）复用是唯一杠杆——定理"值得做"的条件；算力受限区（prefill）复用不影响吞吐——定理"无关"的边界。两者都只是"值不值得落实"，不推翻定理。
- **CXL-SpecKV**（arXiv 2512.11920）：liveness 驱动的 KV 预取与驱逐。活集超容量时的标准处置，即定理不在场情形的妥协。
- **FAST-Prefill**（arXiv 2510.16323）：热/冷 KV 分层 + liveness 驱逐，TTFT 2.5×。同上。
- **FlightLLM / GLITCHES**：权重 read-once 流式，decode 阶段权重从 DDR 读一遍即弃。高速层维持复用、慢层只读一次在现代 LLM 的重现。

## 2.6 证据层地位

以上为**文献层证据**（可回查）。真机层证据只由 k3 真机台账提供（专家段 25.83GB/token 慢盘重读、复用 trace 等），不在此章。误差边界：
- 文献层"快若干倍"数字（如 0.0029、344×、200×）随具体工作量与工艺变化；
- 定理本身（无边界条款版）是逻辑真，不随上述数字浮动。
