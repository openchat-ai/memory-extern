月之暗面做对了什么

1. KDA：把 softmax 退休

69 层线性注意力 + 24 层标准注意力 = 100 万 token 上下文，KV-cache 不随序列长度增长。

这是结构性创新——不是优化 softmax，而是换掉它。

2. AttnRes：让网络学会检索

93 层深的网络，信息不会衰减。每个 block 用注意力机制选择性检索前序 block 的表征。

这是记忆机制创新——从"记忆累加"升级到"记忆检索"。

3. Stable LatentMoE：拆掉 MoE 的地雷

896 个专家，top-16 激活，Quantile Balancing 保证路由均衡，共享专家提供稳定梯度。

这是工程创新——把 MoE 从"能训"变成"能训稳"。

4. SiTU-GLU：被低估的激活函数

在 MXFP4 精度下稳定训练，梯度自然截断，硬件友好。

这是细节创新——一个激活函数的选择，决定了整条量化链路的稳定性。

5. QAT MXFP4：让模型适应硬件

从 SFT 阶段就用 MXFP4 训练，落盘密度 2.12 bit/weight。

这是务实创新——不等硬件跟上，让模型适应现有硬件。

6. Quantile Balancing：不调参的硬保证

用分位数统计直接保证路由均衡，不需要辅助损失，不需要调 λ。

这是方法论创新——从"调参"升级到"用统计方法保证"。

我做对了什么

1. 实测验证

所有人纸上谈兵，我逐字节验证了 K3 的所有参数：

- safetensors 全量 header 扫描：96 分片，497,220 张量，data_offsets 不越界

- kimi-k3-in-c 真实推理：运行时统计与裁决数逐项吻合

- 路由轨迹分析：100K 条真实请求，90% 重复访问，触及池子 12.14%

没有实测，就没有发言权。

2. 发现隐藏税单

trunk 每 token 每层必经，无法稀疏化。在 GPU 上常驻显存（流量为零），在 32GB 台式机上重读 108.8GB。

这是被忽视的真相——所有人都在讨论专家的稀疏红利，没人讨论 trunk 的稠密税。

3. 在消费级硬件上跑通

32GB 台式机 + HDD，首 token 27.5 分钟。慢，但能跑。

1000 元级国产 FPGA，完整数据通路通过 Verilator lint + 仿真。
