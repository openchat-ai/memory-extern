# K3 权重打包格式（T1 定案）

> 状态：**已定案**（2026-08-26，实测逐字节验证）
> 依据：`/model/model-00002-of-000096.safetensors` 逐字节分析 + kimi-k3-in-c 解码核验
> 结论：K3 路由专家采用 **OCP MXFP4（E2M1 nibble × E8M0 scale）**，与 C 端解码完全一致。

## 1. 总体布局

每个路由专家权重（w1/w2/w3）以两个张量落盘：

| 张量 | shape | dtype | 含义 |
|---|---|---|---|
| `weight_packed` | `[out, in/2]` | U8 | 2 个 E2M1 nibble/字节（MXFP4 数据） |
| `weight_scale` | `[out, in/32]` | U8 | E8M0 指数，每 32 元素 1 个 |

实测（layer1.experts0.w1）：
- `packed` `[3072, 1792]` = 5,505,024 字节
- `scale`  `[3072, 112]`  = 344,064 字节
- 比值 1792/112 = 16 字节/组 = **32 元素/组** ✓（group_size=32）

**每元素磁盘字节数 = 0.5（nibble）+ 1/32（scale）= 0.53125**
→ 33,030,144 参数的 expert 正好占 17,547,264 字节（17.55 MB），与裁决一致。

## 2. E2M1 码表（16 值，4-bit）

`1 符号 + 2 指数 + 1 尾数`：

| 码 | 值 | 码 | 值 |
|---|---|---|---|
| 0x0 | 0.0 | 0x8 | -0.0 |
| 0x1 | 0.5 | 0x9 | -0.5 |
| 0x2 | 1.0 | 0xA | -1.0 |
| 0x3 | 1.5 | 0xB | -1.5 |
| 0x4 | 2.0 | 0xC | -2.0 |
| 0x5 | 3.0 | 0xD | -3.0 |
| 0x6 | 4.0 | 0xE | -4.0 |
| 0x7 | 6.0 | 0xF | -6.0 |

（bit3=符号，指数 0-3 尾数 0-1 组合 {0,0.5,1,1.5}×2^e）

## 3. 字节内 nibble 顺序

- **低 nibble（`byte & 0x0F`）= 偶数元素**
- **高 nibble（`byte >> 4`）= 奇数元素**

```c
nib = (i & 1) ? (byte >> 4) : (byte & 0x0F);   /* k3_ops.c:1356 */
orow[i] = K3_E2M1[nib] * mult;
```

> ⚠️ 反转此顺序会得到"值全对但位置全错"的矩阵：统计上完美、推理全错。已用真实 checkpoint 字节验证。

## 4. E8M0 scale

- `value = E2M1[nibble] × 2^(scale_byte - 127)`
- **255 是 NaN（OCP 规格），解码映射为 0**（单字节坏值不污染整行）
- 实测 255 占比 ~0.017%（哨兵存在，符合规格）

## 5. 实测验证证据

逐字节分析（layer1.experts0.w1，3,096×2 码抽样）：

- **nibble 码分布**完全吻合 E2M1 统计特征：码 0/1（0/0.5）最多、码 7/15（±6.0，满指数满尾数）最少（~0.9%），递减梯度与指数-尾数结构一致。
- **解码后 15 值对称**：mean≈-0.077，std≈1.92，正负分布均衡 —— 真实权重特征。
- **scale 值域** `2^(0-127)` ~ `2^(255-127)`，255≈0.017% 为 NaN 哨兵。
- 排除假设 B（4×2bit 无符号码）：该假设下码 {0,1,2,3} 全非负、分布 29.8/23.0/28.1/19.1%，无法解释真实权重的正负对称性；且 E2M1 码 7/15 的稀少在 4×2bit 视角下无法被捕捉。

## 6. 位/字节序与 C 端一致性

| 项 | 值 | C 端出处 |
|---|---|---|
| 打包 | 2×4bit nibble/字节 | `k3.h:525` |
| nibble 序 | low=偶, high=奇 | `k3_ops.c:1356` |
| 码表 | `K3_E2M1[16]` | `k3_ops.c:1027-1030` |
| scale | `ldexpf(1, sb-127)` | `k3_ops.c:1346` |
| 255→0 | NaN 哨兵 | `k3_ops.c:1346` |
| group | 32 元素 | `k3.h:548` `K3_MXFP4_GROUP` |
| 配置 | `quantization_config.group_size=32` | config.json |
