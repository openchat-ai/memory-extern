# 钢筋图 → 3D → 料单 项目起始备忘

> 版本 0.1 · 2026-09-17 · 真实需求驱动：公司图纸是**全打散伪矢量图**（实体全部炸成细短线，连文字字符都炸成轮廓）。
> 客户=公司自己，推广渠道现成（"搞出来很容易全公司推广"）。

## 一、目标链

```
真实钢筋图纸(几十张, 公司财产, 全打散伪矢量)
  → [几何聚类重建] 短线 → 图元/字符轮廓
  → [专用识别桩]  文字(95%可OCR) + 特殊符号(轴号号ⓐⓑⓒ, 钢筋等级φ/Φ/Ҩ等封闭集)
  → [平法解析]    16G101 / 22G101 规则 → 构件+配筋结构化
  → [3D翻模]      中间产物: 梁/柱/墙/板 三维模型
  → [钢筋料单]    最终交付: 下料清单
```

**料单 = 最终目标；3D翻模 = 必要中间产物**（用户确认，不能一步到位）。

## 二、用户侧已确认事实

1. 完整整套钢筋图纸（几十张），**公司的**，在用户电脑里
2. 伪矢量图：全部打散成细短线，**无图层/无图块/无实体语义**
3. **文字也是打散的（字符炸成轮廓线）**；用通用 OCR 勉强识别，5% 关键失败：
   - 带圈轴号（ⓐⓑⓒ 之类）
   - 钢筋等级符号（φ=HPB300 / Φ=HRB400 / 特殊字形）
4. 最终目标是**钢筋料单**，中间产物 3D 翻模
5. 若可行，**全公司推广容易**

## 三、竞品与技术现状（2026-09 调研）

| 阵营 | 代表 | 方法 | 对伪矢量的可用性 |
|---|---|---|---|
| 国产翻样软件 | 广联达 BIMMAKE、e筋、迈思、云识图 | CAD 实体识别(图层/图块/TEXT)+规则 | **不适用**——输入假设实体完整，全打散图直接失败 |
| CAD 插件 | AddoBAR、展志 | 在 CAD 内画智能钢筋对象→自动料单 | 不是识别，是自己画，需要重新建模 |
| 新技术 | RebarViz | LLM 读平法标注截图 | 输入是截图/标注文本，不是打散图 |
| 学术 | ISARC 2026, YOLOv11+TrOCR | 光栅化+深度学习提标注 | 路线可借鉴，但他们**不用矢量精度** |
| 开源 | OpenRebar(.NET) | 等值线 PNG/DXF → 布筋+切割优化 | 输入是等值线图(隔离线)，不是施工图 |

**结论：全打散伪矢量图的"字符几何重建+平法解析"是无人区。**
- 已有玩家全部建立在"实体未炸"或"光栅位图"两条假设上
- 我们的杀手锏 = **矢量坐标精度还在**。炸散文字 = 每个字符是一组精确短线段，可无损重建字形，再做识别——比光栅 OCR（带噪、毛边）强一个量级

## 四、技术路线（当前判断）

```
DXF矢量(导出) ──→ 线段几何聚类(连通+共线) ──→ 图元/字形重建 ──→ 专用OCR
                                                            │
                        特殊符号桩(封闭集: 轴号+钢标) ◄──────┘
                                                            │
                        平法语义解析(16G/22G规则) ──→ 结构化构件 ──→ 3D翻模 ──→ 料单
```

- **为什么走矢量重建而非光栅 MLLM 硬啃**：炸散文字在位图上会带毛边断笔，通用 OCR 只能到 95% 且死在关键符号；矢量重建后字符是无损清晰字形，识别难度骤降，且能把"钢标封闭集"用几何特征（笔画数量/形状）锁死
- 前提：**图纸需能导出 ASCII DXF**（矢量信息才保得住）。若只能拿到位图，则退化为光栅路线（代价：需重训模型，能吃但收益大减）

## 五、分阶段里程碑

- **M0 可行性**：导出 1 张 DXF，确认字符是"轮廓短线"还是"可解实体"；跑通聚类→字形重建（本仓库第一个工具）
- **M1 识别桩**：通用 OCR 精修 + 轴号/钢标符号识别闭环，真实图纸字符级精度 ≥99%
- **M2 平法解析**：某一种构件（先梁）的 16G/22G 标注→结构化数据
- **M3 3D翻模**：梁/柱 三维重建 + 钢筋布置
- **M4 料单**：下料清单出表，钢筋技术员验收（**你就是验收人**）

## 六、风险

1. 若 DWG 连导出 DXF 都做不到（罕见格式）→ 退化成光栅路线，识别桩要重训，成本×3
2. 图纸非标准规范（老图/特殊图例）→ 平法解析容错，需要兜底人工
3. 数据敏感（公司财产）→ 全程本地/内网，K3 部署研究（带宽/量化）正好是这块底子
4. 定义本身：料单正确性=钢筋技术员说了算，从 M1 起就要他对照验收

## 七、与既有资产的关系

- K3/字节账研究 = 端侧部署能力储备（本地模型、多大能跑、量化后性能），M4 才真正用到
- 需要补充技能：DXF 解析（纯 stdlib 可搞）、平法图集规则（16G101/22G101 是公开标准）、几何聚类
- 无 GPU 也能起步 M0-M2（聚类+识别桩可 CPU 跑）；若走光栅 MLLM 才需要 GPU/大模型
