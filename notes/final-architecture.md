## 裸片参数

| 参数 | 值 | 来源 |
|---|---|---|
| MAC 数 | **128 颗，每颗独立 ICG 门控** | ADR v0.4 定案 |
| 时钟 | 500 MHz（成熟工艺保守值） | |
| 计算 | bf16 乘累加 / int4 SIMD×4 | |
| 片上 SRAM | **无** | 寄存器驻留替代 |
| 流式 FIFO | 64 KB 分布式触发器 | RTL 骨架已写 |
| 权重存储 | 片内合封 NAND die ×13（QLC 1Tb） | 直连无协议 |
| NAND 容量 | ~1.66 TB（含 ECC 余量） | |
| 外部内存 | 无 | 全部片上 |

## 数据流

```
NAND die ×13 ──→ 解包器 ──→ DDR4 2GB 双缓冲 ──→ 128 MAC
（1.56TB 权重）   （mxfp4→bf16）   （当前层+预取下一层）
```

| 档位 | 配置 | 市场 |
