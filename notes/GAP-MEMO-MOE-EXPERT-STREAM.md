# 缝隙立项备忘录：MoE 专家流式（Expert Streaming）

> 依据：MARKET-BEFORE-ENGINEERING.md 所立规矩"市场证据先于工程结论"。
> 日期：2026-09-16。状态：证据已收集，待用户决策（立项 / 搁置 / 结案）。
> 证据标记：[证实]=可溯源公开数据；[待证实]=检索可得但未亲自核原件；[疑点]=正反数据冲突。

## 一、结论先行（Verdict）

1. 「RK1828 之外的缝隙」从假设升级为**有市场实测支撑的缝隙**：大参数量 MoE 本地推理的
   **带宽墙是真实产品上已被量出的瓶颈**，且目前没有任何量产商用硬件针对它做专门优化。
2. 但缝隙不是"通用 AI 加速卡"（该位被 RK1828/LQ50 占死），而是**"30B–100B+ MoE 本地推理的
   专家权重流式 + 大容量高速外存"这个窄带**；且窗口期受 RK1880/RK1899（2026 规划）挤压，约 12–18 个月。
3. 推荐路线：**软件先行（K3 真机引擎 + 可复现基准，成本 ≈ 0）→ 再定硬件（PCIe/M.2 外置
   专家流式卡）。** 不推荐一上来自研全芯片（跑不赢 Rockchip 的 TTM 与流片预算）。
4. 政府奖项切点成立：信创/数据不出域有 2027 硬性政策（见 §3.4），无国产 M.2 级产品吃 30B+ 槽位。

**带宽墙的市场实证（关键证据）**：Qwen3.5-35B-A3B 是 MoE（激活仅 3B），算力需求极小，
LQ50 单卡却只有 ≈12 tok/s——瓶颈不在 TOPS，在**专家权重从 153.6GB/s LPDDR5X 流出的
带宽**。这与用户 K3 真机台账（每 token 全量重读 25.83GB、占端到端 94%、
命中率 100% 仍全量读）是同一种病在不同规模上的体现。[证实]

## 三、证据链

### 3.1 学术对手——全是论文/软件，无商用产品（= 未被商业化的证实）
- **FreeToken** (arXiv:2608.16157)：边缘原生 MoE serving，带宽自适应执行 + 语义感知专家缓存；
  笔记本 35B → 游戏台式 284B → 单工作站 753B GLM-5.2。结论原文："消费级 CPU 双通道 DDR
  仅 50–90GB/s，decode 无法独自承载"。**软件路线，无硬件。**
- **APEX** (arXiv:2608.11688)：边缘 MoE 自适应专家预取；**专家加载占延迟 43%、能耗 29%**（Granite-3B）。
- **EdgeXpert** (arXiv:2608.05303)：EMA（外部内存访问）是主要瓶颈，FFN 权重的 EMA 主导。
- **EStream / BigMoMo**：移动 NPU MoE，专家虚拟化 UFS 分页、推测解码（2.25–4.83×加速）。
- **DASH / Trillion-Parameter MoE in a Box** (arXiv:2609.15636)：HBF（高带宽闪存）做 MoE 权重库，数据中心级。
- **推论**：2026 年学术圈在集中烧"专家搬运"，证明**问题真实且开放**；但谁都没把它做成
  量产硬件→卡位机会属于"把 FreeToken/APEX 机制硅化"的人。[证实]

### 3.2 需求端——信创/数据不出域是硬门槛（政策 + 预算）
- 《信创发展规划(2025-2027)》：**2027 年前党政 100%、央企国企 ≥80%、事业单位 ≥60% 国产化率**；
  国资委 79 号文要求央企国企 2027 前完成信息化信创替代。[证实]
- 约束：政企不能调公有云 API、模型参数不得出网，须本地/私有云部署（《数据安全法》《网络安全法》）。[证实]
- 政企预算：区县 20 万 / 地市 50 万 / 省级 120–200 万 / 央企总部 300 万 / 国企分子 80 万；
  工作站 12–25 万 vs 服务器 40–60 万。小微型政企买不起昇腾服务器。[证实]
- 现有商用：LS910（昇腾底、Qwen3.6-27B 私有化，Edge/Max/Pro）、私有化知识库一体机
  （可道云 TeamSilo A10 类）、联想 P3-P7 信创工作站。**这些全在 12 万–68 万档；M.2/桌面档（<5 万）的 30B+ 本地大 MoE 是空的。**[证实]

### 3.3 用户自持优势（本地唯一性）
- K3（2.8T 级 MoE）真机实验 + 台账，**比上述所有论文的测试对象大两个数量级**，是可复现的唯一考证。
- 已有沉淀：预测性驱逐论文、byteflow-matrix、专家 LRU/预取/带宽墙量化、定制引擎（kimi-k3-in-c 仓库）。
- 用户自己已论证的中间结论（内存-extern 路线）：外置内存方案可将 K3 结构 8GB 命中→36%→90%、
  L2 时间下降 33%（见 memory-extern 设计）。[待复核]

## 四、缝隙定义（一句话）

> **30B–100B+ 参数 MoE 在桌面/信创主机上"本地跑得动且带宽不被专家搬运卡死"的
> 硬件+软件方案。** 上界是 RK1828/LQ50（装不下或带宽墙），下界之上是昇腾服务器（太贵），
> 时间上先于 RK1880/1899 量产。

## 五、风险与反证（先看这个再立项）

1. **Rockchip 时间线**：RK186X 已披露"完成研发、2026 Q4 推出"（财闻网 2026-09-08）；
   RK1880/1899 规划 7B–70B。若 2027 年 RK1880 如期量产 34B 档 → 需用"算法/软件生态 + 专家流式专用性"错位竞争，正面刚 TOPS 必输。
2. **后摩生态已先行**：LQ50/LM5070 已量产覆盖 7B–70B（70B 慢），且主打信创/工业。新卡必须比 LQ50
   在**带宽×容量性价比**上赢（其 153.6GB/s / 24GB 是基准线）。
3. **学术软件快速进化**：FreeToken 等若闭源商用 → 软件差异化萎缩，只剩硬件缝隙。
4. **国产大内存供给**：HBM 国产稀缺；可行方案是长鑫/兆易 LPDDR5X（RK1828 已走通 3D 堆叠）或 HBF 闪存。
5. **甲方通路**：政企采购爱打包（硬件+软件+运维整机投标），单片卡难单独进政采，需找整机 OEM/DMB（后摩、万物纵横、格灵深瞳类）挂靠。用户自身在国企 = 潜在首种子客户，但走本司采购需合规。
6. **结论反转条件**（若出现即回到结案）：RK1880/1899 提前量产并支持外部专家流式；LQ50 二代把带宽提到 ≥512GB/s；FreeToken 提交商用硬件。

## 六、路线建议（MVP 三步）

- **Step 0（决策点，成本≈0，1–4 周）**：以现有 K3 引擎 + 台账，跑出"LLM 解码带宽墙 vs 专家流式缓存"的
  可复现开源基准（对比 llama.cpp / FreeToken 基线），目标：>100B MoE 本地 2–3× tok/s 提升并出图。
  产出物=软著/论文/开源 star，为政府申报与后续融资取证。
- **Step 1（若 Step0 数据成立，6–12 月）**：外置专家流式原型=PCIe4 x4 卡 + 大容量 LPDDR5X(≥48GB) +
  专家缓存/预取引擎，接 x86 跑 30–100B MoE；对准"私有化知识库一体机"整机档（<10万）。标杆=LQ50 的 12 tok/s(35B-A3B)。
- **Step 2（市场证据达标后再定）**：决定是否走"品牌整机/OEM 挂靠"还是"纯 IP 授权/流片联合"。

## 七、政府/奖项切点
- 信创专项、国产化替代类科技奖：卡属于"国产化算力部件"，正落在 2027 国产化率考核里。
- 材料构成：软著 + 专利（专家流式预取/多级缓存调度）+ 信创适配（麒麟/UOS）+ 三甲实测 +（若可）市级重点研发计划。
- **注意**：政府奖励依赖的是"能跑 30B+ 的原型 + 国产化部件清单"，论文只是佐证——与职称主线不冲突，反而论文（带宽墙/排查判据）是技术背书。
