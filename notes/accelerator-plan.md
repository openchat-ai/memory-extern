# LLM 推理加速芯片项目计划

> 2026-08-20 定稿。目标：设计一颗专跑 LLM 推理的 GEMV 加速芯片。
>
> **核心洞察**：LLM 推理是内存墙问题，不是算力问题。谁的内存带宽高，谁就赢。
>
> - AccelStack（2025）：只用 H100 39% 的算力，推理吞吐量却是 H100 的 2.09 倍。
> - 原因：3D 堆叠 DRAM 带宽是 HBM 的 3-5 倍。
> - 我们不需要和 GPU 比算力。需要比的是：内存带宽。

## 内存方案矩阵（4 选 1，双源策略）

| 方案 | 供应商 | 带宽（12 颗） | 功耗 | 成本 | 国产 | 适用场景 |
|------|--------|-------------|------|------|------|---------|
| A. GDDR7 | Samsung/SK Hynix/Micron | **1.5 TB/s** | 高 | 中 | 否 | 数据中心，最高性能 |
| B. LPDDR5X（SOCAMM2） | Samsung/SK Hynix/Micron | 460-920 GB/s | 低 | 低 | 否 | 边缘/低功耗 |
| C. LPDDR5X（长鑫 CXMT） | 长鑫存储 | 460 GB/s | 低 | **最低** | **是** | 国产替代，成本优先 |
| D. CXL + DDR5 | 任何 DDR5 厂商 | ~100 GB/s | 低 | 最低 | 可以是 | 超大模型，容量优先 |

**推荐双源策略**：方案 A（GDDR7，高性能）+ 方案 C（长鑫 LPDDR5X，国产备选）。

### 内存方案详细对比

| 指标 | A. GDDR7 | B. LPDDR5X（国际） | C. LPDDR5X（长鑫） | D. CXL+DDR5 |
|------|----------|-------------------|-------------------|-------------|
| 单芯片带宽 | 128 GB/s | 38-76 GB/s | 38 GB/s | ~8 GB/s |
| 总带宽（12 颗） | 1.5 TB/s | 460-920 GB/s | 460 GB/s | ~100 GB/s |
| 容量（12 颗） | 384 GB | 768 GB | 384 GB | TB 级 |
| 延迟 | 10-20 ns | 30-45 ns | 30-45 ns | 70-90 ns |
| 功耗（内存） | 30-50W | 10-20W | 10-20W | 15-30W |
| 供货风险 | 中（AI 抢产能） | 低（手机市场） | **极低**（国产） | 极低 |
| 芯片需支持的 PHY | GDDR7 PHY | LPDDR5X PHY | LPDDR5X PHY | CXL/DDR5 PHY |
| PCB 复杂度 | 高（12 颗 BGA） | 中（PoP/SOCAMM） | 中（PoP） | 低（DIMM） |

### 为什么 GDDR7 不是唯一选择

- GDDR7 带宽最高（1.5 TB/s），但功耗大、散热难、PCB 占地大
- LPDDR5X 功耗低 30-35%，供货更稳定（手机市场驱动）
- 长鑫 LPDDR5X 是国产方案，不受美国制裁，供货最稳
- CXL+DDR5 带宽最低但容量最大，适合超大模型（>100B 参数）

### 芯片设计要点

芯片需要支持**可切换的内存控制器**：
- GDDR7 PHY 和 LPDDR5X PHY 是不同的接口标准
- 一种做法：芯片设计两种 PHY，PCB 按需选择
- 另一种做法：先做 LPDDR5X（更简单），后续版本加 GDDR7
- **推荐**：先做 LPDDR5X（长鑫可供货），验证后再做 GDDR7 版本

## 范围外（停止）

| 工作 | 原因 |
|------|------|
| PIM-DIMM 方案 | 已证伪：做不过 GPU，最终变成 GPU |
| SRAM CIM 阵列 | 需要自造存储，一个人搞不定 |
| CIM 阵列 RTL（DAC→SRAM→ADC） | 属于 SRAM-based CIM，不采用 |
| CPU 端 GEMV 内核优化（NEON/AVX2） | ggml 的活，不是芯片的活 |
| MXFP4 E2M1 引擎 | 真实权重精度不够，已证伪 |
| Q3/Q4 CPU benchmark | 芯片不做 CPU 侧优化 |
| TT 芯片提交 | 无商业价值 |
| 三级预取调度器（sched3/sched4） | 属于缓存架构，芯片不做缓存 |
| 缓存命中率分析 | 软件层问题，芯片不解决 |
| Trace 采集与分析 | 用于验证，不是芯片本身 |
| 芯片间互连/光互连 | 不需要，单芯片足够 |
| 3D 堆叠 | 用不起，成本太高 |
| HBM | 买不到，全给 NVIDIA/AMD 了 |
| GDDR6X | Micron 独家，正在停产 |

## 范围内（该做）

### 架构：单芯片 GEMV 引擎 + 外置内存

```
                    ┌──────────────┐
                    │   GDDR7 或   │
                    │  LPDDR5X     │
                    │  内存颗粒     │
                    └──────┬───────┘
                           │ 内存总线（460 GB/s ~ 1.5 TB/s）
┌──────────────────────────┼──────────────────────────┐
│                          │                          │
│  ┌───────────────────────┴───────────────────────┐  │
│  │           内存控制器（GDDR7 / LPDDR5X）        │  │
│  └───────────────────────┬───────────────────────┘  │
│                          │                          │
│  ┌───────────────────────┴───────────────────────┐  │
│  │         GEMV 计算阵列（252 个 bf16 MAC）       │  │
│  │         + 片上 SRAM 缓冲（2MB）                │  │
│  └───────────────────────┬───────────────────────┘  │
│                          │                          │
│  ┌───────────────────────┴───────────────────────┐  │
│  │           PCIe Gen4 x16 控制器                 │  │
│  └───────────────────────┬───────────────────────┘  │
│                          │                          │
│              逻辑 die（28nm，~50 mm²）               │
└──────────────────────────┼──────────────────────────┘
                           │ PCIe
                     ┌─────┴─────┐
                     │   主机 CPU  │
                     └───────────┘
```

## 风险

| 风险 | 影响 | 缓解 |
|------|------|------|
| 内存供货紧张 | GDDR7/LPDDR5X 都在被 AI 抢 | 双源策略：国际 + 长鑫国产 |
| 长鑫 LPDDR5X 带宽不够 | 460 GB/s 低于 GDDR7 的 1.5 TB/s | 先用 LPDDR5X 验证，后续加 GDDR7 |
| 首个客户找不到 | 产品无法变现 | 先做 FPGA 原型验证价值 |
| 流片失败 | 流片费打水漂 | 多轮仿真 + MPW 试水 |
| 竞品抢先 | 市场被占 | 聚焦细分场景（边缘/低成本/国产替代） |
| 软件生态从零开始 | 用户不愿切换 | llama.cpp 适配降低门槛 |
| 28nm 性能不足 | 时序不满足 | 用成熟 IP，降低频率目标 |

## 技术对标

| 指标 | RTX 3090 | H100 | 我们（LPDDR5X） | 我们（GDDR7） |
|------|----------|------|----------------|--------------|
| 工艺 | 8nm | 4nm | 28nm | 28nm |
| 晶体管 | 283 亿 | 800 亿 | 0.4 亿 | 0.4 亿 |
| 内存带宽 | 936 GB/s | 3.35 TB/s | 460 GB/s | 1.5 TB/s |
| 功耗 | 350W | 700W | ~50W | ~60W |
| 成本 | $1000 | $30000+ | **$350** | **$400** |
| LLM tok/s | ~30-40 | ~60-80 | ~15-20 | ~50 |

**核心结论**：
1. 我们不需要更多晶体管。我们需要更宽的内存通道。
2. 长鑫 LPDDR5X 是国产方案，供货最稳，成本最低，适合第一版芯片。
3. GDDR7 是性能方案，适合第二版芯片，带宽可达 1.5 TB/s。
4. 双源策略（国际 + 国产）确保不怕卡脖子。
