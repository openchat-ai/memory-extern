# LLM 推理芯片项目计划

> 2026-08-20 定稿。
>
> **核心洞察**：LLM 推理是内存墙问题，不是算力问题。谁的内存带宽高，谁就赢。
>
> **产品策略**：同一块 PCB，高低配两代芯片。
> - **V1（先做）**：纯数字 GEMV 加速卡，全直焊 LPDDR5X，能活。
> - **V2（后做）**：同一 PCB，焊上 CIM 芯片，性能突破。

## 产品定义

| 项 | V1（低配） | V2（高配） |
|---|---|---|
| 产品 | PCIe 加速卡 | PCIe 加速卡（+CIM） |
| 主芯片 | GEMV 阵列 + 内存控制器 | 同 V1 |
| CIM 芯片 | **空焊盘（不贴片）** | **焊上 CIM 芯片** |
| 内存 | **全直焊 LPDDR5X**（12 颗） | 同 V1 |
| 工艺 | **14nm FinFET（中芯国际）** | 14nm |
| 功耗 | ~40W | ~55W（+15W CIM） |
| 带宽 | **550 GB/s** | 更高（CIM 加速） |
| 容量 | 24GB / 48GB / 96GB（买时选） | 同 V1 |
| 成本 | ~$250 | ~$350（+CIM 芯片成本） |
| 目标 tok/s | 25-30（7B bf16） | 50-100+ |

## 范围外（不做）

| 工作 | 原因 |
|------|------|
| PIM-DIMM 方案 | 已证伪：做不过 GPU，最终变成 GPU |
| SRAM CIM 阵列（独立模块） | V2 做，V1 不做 |
| CIM 阵列 RTL（DAC→SRAM→ADC） | 属于 V2 CIM 芯片，不在 V1 主芯片内 |
| CPU 端 GEMV 内核优化（NEON/AVX2） | ggml 的活，不是芯片的活 |
| MXFP4 E2M1 引擎 | 真实权重精度不够（p50(max_err)=31%，DAC/ADC 不叠加），已证伪 |
| Q3/Q4 CPU benchmark | 芯片不做 CPU 侧优化 |
| TT 芯片提交 | 无商业价值 |
| 三级预取调度器（sched3/sched4） | 属于缓存架构，芯片不做缓存 |
| 缓存命中率分析 | 软件层问题，芯片不解决 |
| Trace 采集与分析 | 用于验证，不是芯片本身 |
| 芯片间互连/光互连 | 不需要，单芯片足够 |
| 3D 堆叠 | 用不起，成本太高 |
| HBM | 买不到，全给 NVIDIA/AMD 了 |
| GDDR6X | Micron 独家，正在停产 |
| SOCAMM2 插槽 | 带宽掉 3 倍（136 vs 460 GB/s），不值得 |
| 混合直焊+插槽 | 调度复杂，慢的拖累快的 |
| CXL + DDR5 | 带宽太低（~100 GB/s），不够用 |
| GDDR7（V1） | 功耗高、散热难，V2 再考虑 |
| 测试控制器（BIST） | V1 不需要，FPGA 验证够用 |
| profiling 工具 | V1 不需要，量产后再做 |

## 为什么全直焊，不用插槽

| | 全直焊 LPDDR5X | SOCAMM2 插槽 |
|---|---|---|
| 带宽 | **460 GB/s** | 136 GB/s（差 3 倍） |
| 延迟 | **低**（走线短） | 高（模块化损失） |
| 信号质量 | **好** | 差 |
| 可升级 | 不能 | 能 |
| 复杂度 | **低** | 高（两种速度管理） |
| 成本 | **低** | 高（插槽贵） |

**结论**：插槽带宽掉 3 倍，不值得。全直焊最简单、最快、最便宜。

### P1 实测明细（2026-08-20）

- 机器：海光 Hygon C86-3G（Zen 架构，EPYC 同源），8 核 16 线程，32GB DDR4
- 环境：WSL2 Ubuntu + gcc 15.2，`-O2 -march=native -fopenmp`，16 线程
- 方法：STREAM v5.10，数组 4×488MB（2GB 总量，超出 L3），NTIMES=10
- 结果（MB/s，取 min time）：

| 内核 | 单线程 | 16 线程 |
|------|--------|---------|
| Copy | 20,782 | 29,343 |
| Scale | 11,103 | 16,587 |
| Add | 14,566 | 18,257 |
| Triad | 14,265 | 18,033 |

- 结论：实测峰值 ~29 GB/s（Copy），远低于计划假设的 LPDDR5X 460 GB/s（差 16×）。EPYC 实际跑 GEMV 时**内存带宽是硬瓶颈**，不是算力。V1 芯片若只靠 LPDDR5X 直焊，单 die 460 GB/s 的假设需按实际 PHY 能力重估。

### P2 修正明细（2026-08-20）

- 旧值 252 MAC 按 GDDR6X 384 GB/s 估算；新值按 LPDDR5X 460 GB/s：
  `460 GB/s ÷ 4 bytes/MAC = 115 GMAC/s @1GHz → 115 个 bf16 MAC`
- 已同步 `pim/estimate_transistors.py`（带宽口径 12×38=456 → 460，MAC=115）
- 重算结果（28nm，8M T/mm²，容量 2MB SRAM + PCIe Gen4 x16）：

| 项 | 252 MAC（旧） | 115 MAC（新） |
|----|---------------|---------------|
| MAC 阵列晶体管 | 1.0M | 0.46M |
| 总晶体管 | 387.1M | 386.0M |
| die 面积 | ~48 mm² | 48.3 mm² |
| 总功耗（含内存） | 101W | 76W |

- 结论：MAC 阵列本身只占总量 0.1%（SRAM 2MB 占 87% 是绝对大头），MAC 数修正对面积几乎无影响（48.3 vs 48.4 mm²），但功耗显著下降（101→76W，-25%）。**面积瓶颈是 SRAM，不是 MAC。** 若需减面积，应优先砍 SRAM 容量而非 MAC 阵列。

### P2 工艺升级 14nm 重算（2026-08-20）

- 工艺升级 14nm FinFET 后（详见 `notes/process-comparison.md`，30M T/mm²、0.75V、1.4 GHz）重算：

| 项 | 28nm | 14nm |
|----|------|------|
| MAC 阵列 | 14.4 mm² | **3.8 mm²** |
| SRAM 2MB | 8 mm² | **3 mm²** |
| PCIe + 内存控制器 + 其他 | 20 mm² | **8 mm²** |
| die 面积 | ~42 mm² | **~15 mm²**（3.75x 缩小） |
| 总晶体管 | ~340M | ~450M（+30%，FinFET 结构） |
| MAC 频率 | 1 GHz | **1.4 GHz**（161 GMAC/s，+40%） |
| DDR 带宽 | 460 GB/s | **550 GB/s**（+20%） |
| 总功耗 | ~50W | **~40W**（0.75V 低压） |
| 每片 die 成本（量产） | ¥7.7 | **¥4.0**（面积小 > 晶圆贵） |
| MPW 拼片 | ¥50-150 万 | **¥100-300 万** |

- 结论：**14nm 全面优于 28nm**——面积小 3.75 倍、频率高 40%、功耗低、量产每片成本减半；代价是 MPW 贵 50-150 万、设计难度中（FinFET 特殊规则）。**P2 完成：V1 主芯片 14nm 定标，~15mm²，~40W。**

- `process-comparison.md` 成本表：**28nm MPW ¥50-150 万，14nm MPW ¥100-300 万**。
- 14nm die 面积大幅缩小（~15mm²，约为 28nm 的 1/3），拼片面积占比低，可能落在区间下限附近。
- 单片参考价（2023）：格芯 10506 元、中芯 6976 元、联电 6501 元、华虹最低。
- 渠道：中芯国际 14nm 直接销售、HICC（杭州芯火）等 MPW 中介。
- **待办**：带 die 面积（~15mm²）向中芯国际 14nm 正式询 MPW 拼片价与交期。

**评估结论**：F1"没有 PHY = 没有芯片"风险显著下降（国产方案存在、带宽够、14nm 已量产）；F4 成本 14nm 更高（¥100-300 万 vs 28nm ¥50-150 万），但换来量产 die 成本减半（¥4.0 vs ¥7.7）——若 V1 预期量较大，14nm 划算；若只做样机，28nm 更省。P3/P4 的启动前确认动作不变，确定性与信息质量已提升。

## PIM 精度模拟结果（2026-08-20，`tools/pim_sim_full.py`，733 tensor / 472 有效）

```
mxfp4            p50(max_err) = 3.1e-1    ← cell 表示饱和（8 档电平不够）
int8_blk32       p50           = 1.1e-2    ← cell + DAC10 + ADC12 + noise 全部叠加
int8_blk256      p50           = 1.4e-2
int6_blk32       p50           = 3.4e-2    ← 边界可用
dac_adc_only     p50           = 2.9e-3    ← 外围量化不是瓶颈
cell_only_int8   p50           = 8.1e-3    ← 纯 cell 量化误差
```

结论：
1. MXFP4 精度不可用（p50=31%），DAC/ADC 噪声在此之上不叠加
2. 8-bit uniform cell (blk32) 精度可行（p50=1.1%），源量化类型差异 <2×
3. 6-bit cell 边界可用（p50=3.4%）
4. PIM 精度不是瓶颈，带宽才是。PIM 硬件方向仍取决于能否做足够高的带宽

## 核心结论

1. **全直焊 LPDDR5X**：460 GB/s 带宽，不用插槽，最简单最快最便宜。
2. **同一块 PCB 做高低配**：V1 空焊盘，V2 贴 CIM 芯片。PCB 只设计一次。
3. **V1 是生存**：纯数字，简单，能活。用成熟技术验证商业价值。
4. **V2 是突破**：CIM 芯片独立设计、独立流片，失败不影响 V1。
5. **三种容量可选**：24G / 48G / 96G，买时选好。
6. **已有 RTL 可复用**：BF16/FP32/add/scale/MAC 已验证，省 2-3 月开发时间。
7. **启动资金**：V1 需要 150-300 万 RMB，V2 追加 190-400 万 RMB。
