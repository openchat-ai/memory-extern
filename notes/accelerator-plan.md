# LLM 推理芯片项目计划（双轨路线）

> 2026-08-20 定稿。
>
> **核心洞察**：LLM 推理是内存墙问题，不是算力问题。谁的内存带宽高，谁就赢。
>
> **双轨策略**：
> - **路线 A（加速卡）**：先活下来。用 LPDDR5X/GDDR7 做 PCIe 加速卡，验证商业价值。
> - **路线 B（CIM 模块）**：再突破。用 SRAM-based CIM 做智能内存模块，突破带宽极限。

## 路线 A：GEMV 加速卡（Phase 1，先做）

### 产品定义

| 项 | 规格 |
|---|---|
| 产品 | PCIe 加速卡 |
| 目标负载 | LLM 推理（GEMV 为主） |
| 工艺 | 28nm |
| 晶体管 | ~400M（0.4B） |
| 芯片面积 | ~50 mm² |
| 内存 | 4 种方案可选（见下方） |
| 接口 | PCIe Gen4 x16 |
| 功耗 | ~50W |
| 成本 | ~$350 |
| 目标 tok/s | 15-50（取决于内存方案） |

### 内存方案矩阵（4 选 1，双源策略）

| 方案 | 供应商 | 带宽（12 颗） | 功耗 | 成本 | 国产 | 适用场景 |
|------|--------|-------------|------|------|------|---------|
| A. GDDR7 | Samsung/SK Hynix/Micron | **1.5 TB/s** | 高 | 中 | 否 | 数据中心，最高性能 |
| B. LPDDR5X（SOCAMM2） | Samsung/SK Hynix/Micron | 460-920 GB/s | 低 | 低 | 否 | 边缘/低功耗 |
| C. LPDDR5X（长鑫 CXMT） | 长鑫存储 | 460 GB/s | 低 | **最低** | **是** | 国产替代，成本优先 |
| D. CXL + DDR5 | 任何 DDR5 厂商 | ~100 GB/s | 低 | 最低 | 可以是 | 超大模型，容量优先 |

**推荐双源策略**：方案 A（GDDR7，高性能）+ 方案 C（长鑫 LPDDR5X，国产备选）。

### 芯片架构

```
外部内存（GDDR7 / LPDDR5X / DDR5）
    ↓ 内存总线（100 GB/s ~ 1.5 TB/s）
┌──────────────────────────────────┐
│  内存控制器（可切换 PHY）          │
│  ↓                               │
│  GEMV 计算阵列（252 bf16 MAC）   │
│  + 片上 SRAM 缓冲（2MB）         │
│  ↓                               │
│  PCIe Gen4 x16 控制器            │
│  逻辑 die（28nm，~50 mm²）       │
└──────────────────────────────────┘
    ↓ PCIe
  主机 CPU
```

## 路线 B：CIM 智能内存模块（Phase 2，后做）

### 产品定义

| 项 | 规格 |
|---|---|
| 产品 | DIMM 模块（智能内存） |
| 目标负载 | LLM 推理（GEMV，存内计算） |
| 工艺 | 28nm（CIM 阵列） |
| 内存 | SRAM-based CIM 阵列（片上） |
| 接口 | DDR4/DDR5 DIMM 插槽（对主机透明） |
| 功耗 | ~15-30W |
| 带宽 | **理论无限**（CIM 无总线瓶颈） |

### CIM 架构原理

```
传统加速卡：                     CIM 模块：
CPU → 总线 → 加速卡 → 总线 → CPU   CPU → DIMM 插槽 → CIM 模块
     （数据搬运是瓶颈）                  （存储自己算，无搬运）

传统：SRAM → 总线 → MAC 阵列        CIM：SRAM cell 本身做乘加
     （带宽被总线限制）                  （没有总线，带宽无限）
```

### CIM 技术挑战

| 挑战 | 难度 | 说明 |
|------|------|------|
| DAC（数模转换） | 高 | 输入激活需要转成模拟电压 |
| SRAM 阵列计算 | 高 | 每个 cell 做乘加，精度受限 |
| ADC（模数转换） | 高 | 输出需要转回数字 |
| 精度 | 高 | 模拟计算有噪声，需要校准 |
| 良率 | 高 | 模拟电路对工艺变化敏感 |
| 编程模型 | 中 | 软件需要适配 CIM 架构 |

### CIM 项目阶段（在路线 A 验证后启动）

| 阶段 | 任务 | 时间 | 说明 |
|------|------|------|------|
| B1 | CIM 架构研究 | 3-6 月 | DAC/SRAM/ADC 设计、精度分析 |
| B2 | CIM 阵列 RTL + 模拟 | 6-12 月 | 数字控制 + 模拟前端 |
| B3 | 验证 | 3-6 月 | 混合信号仿真 |
| B4 | 流片 | 3-6 月 | 28nm MPW |
| B5 | 系统集成 | 2-3 月 | DIMM 模块 PCB |
| **合计** | | **17-33 月** | |

### CIM 启动资金（追加）

| 项 | 费用（RMB） |
|---|---|

## 双轨时间线

```
2026 Q3-Q4    2027 Q1-Q2    2027 Q3-Q4    2028 Q1-Q2    2028 Q3-Q4
    │              │              │              │              │
    ▼              ▼              ▼              ▼              ▼
┌─────────────────────────┐
│  路线 A：加速卡          │
│  架构→RTL→验证→流片→量产  │
└─────────────┬───────────┘
              │ 验证通过，找到客户
              ▼
              ┌─────────────────────────────────┐
              │  路线 B：CIM 模块                 │
              │  研究→设计→流片→量产               │
              └─────────────────────────────────┘
```

**关键决策点**：
- 路线 A 验证通过（能跑 LLM、有客户意向）→ 启动路线 B
- 路线 A 失败 → 重新评估是否继续

## 推广路径

| 步骤 | 路线 A（加速卡） | 路线 B（CIM 模块） |
|------|----------------|-------------------|
| 1 | 第一片自己用，验证能跑 LLM | 研究阶段，发论文/申请专利 |
| 2 | 第二片送大佬/投资人 | 原型验证，展示 CIM 概念 |
| 3 | 等订单，小批量生产 | 找合作方（内存厂/服务器厂） |
| 4 | 量产，占领市场 | 量产，替换标准 DIMM |

## 风险

| 风险 | 路线 | 影响 | 缓解 |
|------|------|------|------|
| 内存供货紧张 | A | 芯片没内存可用 | 双源策略（国际+长鑫） |
| 流片失败 | A/B | 费用打水漂 | 多轮仿真+MPW |
| 首个客户找不到 | A | 无法变现 | 先做 FPGA 原型验证 |
| CIM 精度不够 | B | 计算结果不准 | 校准算法+冗余设计 |
| CIM 良率低 | B | 封装成本高 | 先小规模验证 |
| 竞品抢先 | A/B | 市场被占 | A 聚焦成本，B 聚焦带宽 |
| 软件生态 | A/B | 用户不愿切换 | llama.cpp 适配 |

## 技术对标

| 指标 | RTX 3090 | H100 | 路线 A（加速卡） | 路线 B（CIM） |
|------|----------|------|----------------|--------------|
| 产品形态 | 加速卡 | 加速卡 | **加速卡** | **DIMM 模块** |
| 工艺 | 8nm | 4nm | 28nm | 28nm |
| 内存带宽 | 936 GB/s | 3.35 TB/s | 460 GB/s ~ 1.5 TB/s | **理论无限** |
| 功耗 | 350W | 700W | ~50W | ~15-30W |
| 成本 | $1000 | $30000+ | **$350** | **$100-200** |

| 竞争对手 | NVIDIA | NVIDIA | NVIDIA/AMD | UPMEM/大厂 |

## 核心结论

1. **路线 A 是生存**：用成熟技术（LPDDR5X/GDDR7）做加速卡，验证商业价值，赚第一桶金。
2. **路线 B 是突破**：用 CIM 技术做智能内存模块，突破带宽极限，建立技术壁垒。
3. **两条路不矛盾**：路线 A 的芯片设计经验可以直接用于路线 B 的数字控制部分。
4. **启动资金**：路线 A 需要 150-300 万 RMB，路线 B 追加 220-450 万 RMB。总计 370-750 万 RMB。
