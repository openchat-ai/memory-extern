# LLM 推理芯片项目计划

> 2026-08-20 定稿。
>
> **核心洞察**：LLM 推理是内存墙问题，不是算力问题。谁的内存带宽高，谁就赢。
>
> **产品策略**：同一块 PCB，高低配两代芯片。
> - **V1（先做）**：纯数字 GEMV 加速卡，能活。
> - **V2（后做）**：同一 PCB，焊上 CIM 芯片，性能突破。

## 产品定义

| 项 | V1（低配） | V2（高配） |
|---|---|---|
| 产品 | PCIe 加速卡 | PCIe 加速卡（+CIM） |
| 主芯片 | GEMV 阵列 + 内存控制器 | 同 V1 |
| CIM 芯片 | **空焊盘（不贴片）** | **焊上 CIM 芯片** |
| 内存 | LPDDR5X / GDDR7 | 同 V1 |
| 工艺 | 28nm | 28nm |
| 功耗 | ~50W | ~65W（+15W CIM） |
| 带宽 | 460 GB/s ~ 1.5 TB/s | **更高**（CIM 加速） |
| 成本 | ~$350 | ~$450（+CIM 芯片成本） |
| 目标 tok/s | 15-50 | 50-100+ |

## 芯片设计（两颗独立 die）

### Die 1：主芯片（先流片）

```
┌──────────────────────────────┐
│  内存控制器（LPDDR5X / GDDR7）│
│  ↓                           │
│  GEMV 计算阵列（252 bf16 MAC）│
│  + 片上 SRAM（2MB）          │
│  ↓                           │
│  CIM 接口（预留，V1 不连）    │
│  ↓                           │
│  PCIe Gen4 x16 控制器        │
│  28nm，~50 mm²               │
└──────────────────────────────┘
```

### Die 2：CIM 芯片（后流片）

```
┌──────────────────────────────┐
│  SRAM-based CIM 阵列         │
│  （存内计算，无总线瓶颈）      │
│  ↓                           │
│  DAC（数模转换）              │
│  ↓                           │
│  ADC（模数转换）              │
│  ↓                           │
│  数字控制接口（连主芯片）      │
│  28nm，~30 mm²               │
└──────────────────────────────┘
```

## 推广路径

| 步骤 | V1（低配） | V2（高配） |
|------|-----------|-----------|
| 1 | 第一片自己用，验证能跑 LLM | CIM 研究阶段，发论文/申请专利 |
| 2 | 第二片送大佬/投资人 | V1 客户升级：焊上 CIM 芯片 |
| 3 | 等订单，小批量生产 | V2 量产，性能翻倍 |
| 4 | 量产，占领市场 | 新客户直接买 V2 |

## 风险

| 风险 | 影响 | 缓解 |
|------|------|------|
| 内存供货紧张 | V1 芯片没内存可用 | 双源策略（国际+长鑫） |
| V1 流片失败 | 费用打水漂 | 多轮仿真+MPW |
| 首个客户找不到 | 无法变现 | 先做 FPGA 原型验证 |
| CIM 芯片精度不够 | V2 计算结果不准 | 校准算法+V1 仍可用 |
| CIM 芯片良率高 | V2 成本高 | V1 已经赚钱，可以承受 |
| 竞品抢先 | 市场被占 | V1 聚焦成本，V2 聚焦带宽 |
| 软件生态 | 用户不愿切换 | llama.cpp 适配 |

## 核心结论

1. **同一块 PCB 做高低配**：V1 空焊盘，V2 贴 CIM 芯片。PCB 只设计一次。
2. **V1 是生存**：纯数字，简单，能活。用成熟技术验证商业价值。
3. **V2 是突破**：CIM 芯片独立设计、独立流片，失败不影响 V1。
4. **CIM 是可选升级**：V1 客户可以后期购买 CIM 芯片升级，不用换板。
5. **启动资金**：V1 需要 150-300 万 RMB，V2 追加 190-400 万 RMB。
