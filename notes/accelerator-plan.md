# LLM 推理芯片项目计划

> 2026-08-20 定稿。
>
> **核心洞察**：LLM 推理是内存墙问题，不是算力问题。谁的内存带宽高，谁就赢。
>
> **产品策略**：同一块 PCB，高低配两代芯片。
> - **V1（先做）**：纯数字 GEMV 加速卡，全直焊 LPDDR5X，能活。
> - **V2（后做）**：同一 PCB，焊上 CIM 芯片，性能突破。

## 产品定义

| 项 | V1（低配） | V2（高配） |
|---|---|---|
| 产品 | PCIe 加速卡 | PCIe 加速卡（+CIM） |
| 主芯片 | GEMV 阵列 + 内存控制器 | 同 V1 |
| CIM 芯片 | **空焊盘（不贴片）** | **焊上 CIM 芯片** |
| 内存 | **全直焊 LPDDR5X**（12 颗） | 同 V1 |
| 工艺 | 28nm | 28nm |
| 功耗 | ~50W | ~65W（+15W CIM） |
| 带宽 | **460 GB/s** | **更高**（CIM 加速） |
| 容量 | 24GB / 48GB / 96GB（买时选） | 同 V1 |
| 成本 | ~$350 | ~$450（+CIM 芯片成本） |
| 目标 tok/s | 15-25（7B bf16） | 50-100+ |

## 为什么全直焊，不用插槽

| | 全直焊 LPDDR5X | SOCAMM2 插槽 |
|---|---|---|
| 带宽 | **460 GB/s** | 136 GB/s（差 3 倍） |
| 延迟 | **低**（走线短） | 高（模块化损失） |
| 信号质量 | **好** | 差 |
| 可升级 | 不能 | 能 |
| 复杂度 | **低** | 高（两种速度管理） |
| 成本 | **低** | 高（插槽贵） |

**结论**：插槽带宽掉 3 倍，不值得。全直焊最简单、最快、最便宜。

## 内存配置（买时选）

| 型号 | DRAM 数量 | 容量 | 带宽 | 适用模型 |
|------|----------|------|------|---------|
| V1-24G | 12 × 16Gb | 24 GB | 460 GB/s | 7B bf16 / 13B int4 |
| V1-48G | 12 × 32Gb | 48 GB | 460 GB/s | 13B bf16 / 30B int4 |
| V1-96G | 12 × 64Gb | 96 GB | 460 GB/s | 30B bf16 / 70B int4 |

**推荐首选**：V1-48G（覆盖大部分场景）

**内存供应商**：
- 首选：长鑫 CXMT（国产，成本最低，供货最稳）
- 备选：Samsung / SK Hynix / Micron（LPDDR5X，10667 Mbps）

## 芯片设计（两颗独立 die）

### Die 1：主芯片（先流片）

```
┌──────────────────────────────────┐
│  LPDDR5X 内存控制器（8 通道）     │
│  ↓                               │
│  GEMV 计算阵列（252 bf16 MAC）   │
│  + 片上 SRAM（2MB）              │
│  ↓                               │
│  CIM 接口（预留，V1 不连）        │
│  ↓                               │
│  PCIe Gen4 x16 控制器            │
│  28nm，~50 mm²                   │
│  ~400M 晶体管                    │
└──────────────────────────────────┘
```

### Die 2：CIM 芯片（后流片）

```
┌──────────────────────────────────┐
│  SRAM-based CIM 阵列             │
│  （存内计算，无总线瓶颈）          │
│  ↓                               │
│  DAC（数模转换）                  │
│  ↓                               │
│  ADC（模数转换）                  │
│  ↓                               │
│  数字控制接口（连主芯片）          │
│  28nm，~30 mm²                   │
└──────────────────────────────────┘
```

## 推广路径

| 步骤 | V1（低配） | V2（高配） |
|------|-----------|-----------|
| 1 | 第一片自己用，验证能跑 LLM | CIM 研究阶段，发论文/申请专利 |
| 2 | 第二片送大佬/投资人 | V1 客户升级：焊上 CIM 芯片 |
| 3 | 等订单，小批量生产 | V2 量产，性能翻倍 |
| 4 | 量产，占领市场 | 新客户直接买 V2 |

## 风险

| 风险 | 影响 | 缓解 |
|------|------|------|
| 内存供货紧张 | 芯片没内存可用 | 长鑫 CXMT 国产首选 + 国际备选 |
| V1 流片失败 | 费用打水漂 | 多轮仿真 + MPW |
| 首个客户找不到 | 无法变现 | 先做 FPGA 原型验证 |
| CIM 芯片精度不够 | V2 计算结果不准 | 校准算法 + V1 仍可用 |
| CIM 芯片良率低 | V2 成本高 | V1 已经赚钱，可以承受 |
| 竞品抢先 | 市场被占 | V1 聚焦成本，V2 聚焦带宽 |
| 软件生态 | 用户不愿切换 | llama.cpp 适配 |
| DRAM 直焊不可升级 | 客户容量需求变化 | 提供 24G/48G/96G 三种型号 |

## 核心结论

1. **全直焊 LPDDR5X**：460 GB/s 带宽，不用插槽，最简单最快最便宜。
2. **同一块 PCB 做高低配**：V1 空焊盘，V2 贴 CIM 芯片。PCB 只设计一次。
3. **V1 是生存**：纯数字，简单，能活。用成熟技术验证商业价值。
4. **V2 是突破**：CIM 芯片独立设计、独立流片，失败不影响 V1。
5. **三种容量可选**：24G / 48G / 96G，买时选好。
6. **启动资金**：V1 需要 150-300 万 RMB，V2 追加 190-400 万 RMB。
