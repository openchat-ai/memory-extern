# LLM 推理芯片项目计划

> 2026-08-20 定稿。
>
> **核心洞察**：LLM 推理是内存墙问题，不是算力问题。谁的内存带宽高，谁就赢。
>
> **产品策略**：同一块 PCB，V1 纯数字加速卡，CIM 不进 PCB。
> - **V1（先做）**：纯数字 GEMV 加速卡，全直焊 LPDDR5X，能活。
> - **CIM（演进）**：独立芯片 + PCB 焊盘方案已否决，改为 die 内集成或 DRAM 近存。

## 范围外（不做）

| 工作 | 原因 |
|------|------|
| PIM-DIMM 方案 | 已证伪：做不过 GPU，最终变成 GPU |
| SRAM CIM 阵列（独立模块） | 已否决：独立芯片 + PCB 焊盘方案不成立，见"芯片设计"节 |
| CIM 阵列 RTL（DAC→SRAM→ADC） | 若做 CIM，集成进主芯片 die 或 DRAM 近存（独立 V2 项目） |
| CPU 端 GEMV 内核优化（NEON/AVX2） | ggml 的活，不是芯片的活 |
| MXFP4 E2M1 引擎 | 真实权重精度不够（p50(max_err)=31%，DAC/ADC 不叠加），已证伪 |
| Q3/Q4 CPU benchmark | 芯片不做 CPU 侧优化 |
| TT 芯片提交 | 无商业价值 |
| 三级预取调度器（sched3/sched4） | 属于缓存架构，芯片不做缓存 |
| 缓存命中率分析 | 软件层问题，芯片不解决 |
| Trace 采集与分析 | 用于验证，不是芯片本身 |
| 芯片间互连/光互连 | 不需要，单芯片足够 |
| 3D 堆叠 | 用不起，成本太高 |
| HBM | 买不到，全给 NVIDIA/AMD 了 |
| GDDR6X | Micron 独家，正在停产 |
| SOCAMM2 插槽 | 带宽掉 3 倍（136 vs 68 GB/s），不值得 |
| 混合直焊+插槽 | 调度复杂，慢的拖累快的 |
| CXL + DDR5 | 带宽太低（~100 GB/s），不够用 |
| GDDR7（V1） | 功耗高、散热难，V2 再考虑 |
| 测试控制器（BIST） | V1 不需要，FPGA 验证够用 |
| profiling 工具 | V1 不需要，量产后再做 |

## 为什么全直焊，不用插槽

| | 全直焊 LPDDR5X | SOCAMM2 插槽 |
|---|---|---|
| 带宽 | **68 GB/s**（4ch） | 136 GB/s（8ch，但插槽损耗） |
| 延迟 | **低**（走线短） | 高（模块化损失） |
| 信号质量 | **好** | 差 |
| 可升级 | 不能 | 能 |
| 复杂度 | **低** | 高（两种速度管理） |
| 成本 | **低** | 高（插槽贵） |

**结论**：插槽带宽掉 3 倍，不值得。全直焊最简单、最快、最便宜。

### CIM 演进（不做独立芯片）

独立 CIM 芯片 + PCB 预留焊盘方案已否决，理由：

1. **封装放不下**：CIM die ~10mm²，焊盘只给 20mm²，最小 BGA 封装 27mm² 起，模拟芯片（DAC/ADC 引脚多）需 64mm² 才现实。
2. **模拟 SI/PI 无法预留**：AVDD/DVDD/VREF/地岛隔离、去耦位由 PCB 层叠决定，V1 纯数字设计未做这些。
3. **原理上不是存内计算**：独立芯片离 DRAM 数十毫米走线，带宽墙照样在，绕一圈什么都没省。

CIM 的正确形态二选一（独立 V2 项目）：
- **集成进主芯片 die**：V1 架构规划时在 die 内预留接口
- **DRAM 近存**：CIM 进 LPDDR5X 侧，与 V1 PCB 无关

### P1 实测明细（2026-08-20）

- 机器：海光 Hygon C86-3G（Zen 架构，EPYC 同源），8 核 16 线程，32GB DDR4
- 环境：WSL2 Ubuntu + gcc 15.2，`-O2 -march=native -fopenmp`，16 线程
- 方法：STREAM v5.10，数组 4×488MB（2GB 总量，超出 L3），NTIMES=10
- 结果（MB/s，取 min time）：

| 内核 | 单线程 | 16 线程 |
|------|--------|---------|
| Copy | 20,782 | 29,343 |
| Scale | 11,103 | 16,587 |
| Add | 14,566 | 18,257 |
| Triad | 14,265 | 18,033 |

- 结论：实测峰值 ~29 GB/s（Copy），远低于早期假设的 LPDDR5X 460 GB/s（差 16×）。EPYC 实际跑 GEMV 时**内存带宽是硬瓶颈**，不是算力。V1 芯片最终按单 die 4ch = 68 GB/s 定标（34 MAC），多芯片扩展补带宽（见 P2 明细）。

### P2 修正明细（2026-08-20）

- **2026-08-20 二次修正（远端 `778e733`）**：115 MAC 假设 12 颗 LPDDR5X = 460 GB/s 是**错的**——单芯片只能接 4 通道（4ch × 2B × 8533 MT/s = **68.3 GB/s**）。**MAC 由内存带宽决定：252→115→34**。详见 `notes/mac-vs-bandwidth.md`。
- 一次修正（252→115）：旧值 252 MAC 按 GDDR6X 384 GB/s 估算；新值按 LPDDR5X 460 GB/s → `460 ÷ 4 = 115 GMAC/s → 115 MAC`。**该假设已被二次修正推翻（460 GB/s 需 12 颗 DRAM 才成立，单芯片物理不可行）。**
- 最终修正（115→34）：`68.3 GB/s ÷ 4 bytes = 17 MAC`（理论最大）；选用 **34 MAC**（考虑突发/效率余量，且多芯片扩展时 SerDes 互连带宽复用）。已同步 `pim/estimate_transistors.py`（4ch=68 GB/s，34 MAC，4MB SRAM）。

### P2 工艺升级 14nm 重算（2026-08-20，34 MAC 口径）

- 14nm FinFET（中芯国际，55M T/mm²、0.75V、1.2 GHz）重算结果（`pim/estimate_transistors.py`）：

| 项 | 值 |
|----|-----|
| MAC 阵列 | 34 × 4,000 = 0.14M T（0.1%） |
| SRAM 4MB | 81.9M T（**54.6% 面积，最大头**） |
| LPDDR5X PHY 4ch | 20.0M T（24.0%） |
| SerDes 互连 8 lanes | 16.0M T |
| PCIe Gen4 x16 + 控制 + 其他 | 32.0M T（21.3%） |

| 总功耗 | **16.3W**（动态 16.2 + 静态 0.1） |
| 内存带宽 | **68 GB/s**（4ch） |

| 量产成本 | **¥91/颗**（¥200 万 MPW，2.2 万颗） |

- 结论：**面积/功耗从 115 MAC 口径的 15mm²/40W 降为 2.7mm²/16W**。面积大头仍是 SRAM（54.6%）。**架构转向多芯片扩展**：2/4/8 颗 = 137/274/548 GB/s、9.8/19.5/38.8 tok/s、¥182/¥364/¥728（对标 RTX 3090 的 548 GB/s/38.8 tok/s/350W/¥1万+）。

## PIM 精度模拟结果（2026-08-20，`tools/pim_sim_full.py`，733 tensor / 472 有效）

```
mxfp4            p50(max_err) = 3.1e-1    ← cell 表示饱和（8 档电平不够）
int8_blk32       p50           = 1.1e-2    ← cell + DAC10 + ADC12 + noise 全部叠加
int8_blk256      p50           = 1.4e-2
int6_blk32       p50           = 3.4e-2    ← 边界可用
dac_adc_only     p50           = 2.9e-3    ← 外围量化不是瓶颈
cell_only_int8   p50           = 8.1e-3    ← 纯 cell 量化误差
```

结论：
1. MXFP4 精度不可用（p50=31%），DAC/ADC 噪声在此之上不叠加
2. 8-bit uniform cell (blk32) 精度可行（p50=1.1%），源量化类型差异 <2×
3. 6-bit cell 边界可用（p50=3.4%）
4. PIM 精度不是瓶颈，带宽才是。PIM 硬件方向仍取决于能否做足够高的带宽

## 核心结论

1. **全直焊 LPDDR5X**：单芯片 4ch = 68 GB/s，SerDes 互连多芯片扩展到 548 GB/s，不用插槽，最简单最快最便宜。
2. **不预留 CIM 焊盘**：独立 CIM 芯片 + PCB 焊盘的方案已否决（封装放不下、模拟 SI/PI 无法预留、原理上不是存内计算）。PCB 只做 V1 纯数字设计。
3. **V1 是生存**：纯数字，简单，能活。用成熟技术验证商业价值。
4. **CIM 是演进**：若做，集成进主芯片 die 或 DRAM 近存，独立 V2 项目，不占 V1 PCB。
5. **三种容量可选**：24G / 48G / 96G，买时选好。
6. **已有 RTL 可复用**：BF16/FP32/add/scale/MAC 已验证，省 2-3 月开发时间。
7. **启动资金**：V1 需要 364-808 万 RMB（14nm MPW + PHY 授权），V2 追加 253-615 万 RMB。
