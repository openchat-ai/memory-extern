## 一、先纠后证：预测式在线可否兑现，真机记录说了算

README 把"预测式预取（层热度 top-N）"标为**可信度=中、缺真机验证**——它是否是
÷6.38 在线对价的关键。真机 C 档（热表紧 LUR）就是"热度知识→部署"在线化实验，
cross-trace 结果就是判据。

## 三、2×2 交叉热表泛化矩阵（真机铁证，cap63 / 4GiB 减 miss）

| 负载 \ 热表 | 无pin(B) | heat1 | heat2 |
|---|---|---|---|
| trace-1 负载 | 7,666 | **6,304** (−17.8%) | 6,504 (−15.2%) |
| trace-2 负载 | 6,390 | **7,049** (+10.3%) | 未测 |

- **同分布有效**：load1+heat1 减 miss −17.8%（跨 token 稳定）。
- **交叉不对称**：load1+heat2（→）−15.2% 仍利；**load2+heat1（←）反亏 +10.3%**。
- 即"层热度从 trace-A 学到、部署到 trace-B"在真机上**不是总能迁移**——方向性失败存在。

## 四、对预测式/÷6.38 坍缩点的最终裁决（真机证据）

1. **同分布预测式成立（低风险）**：历史热度在同类负载下真机 −17.8% miss，在线可兑现。
   层切换预取 top-K（=predictive in sim_cache）的可行性得到真机同类背书。
2. **跨分布预测式危险（真坍缩点坐实）**：load2+heat1 反亏 +10.3% → **离线层热表不能
   假设跨负载通用**。这正是 README §5.11 的"预测式可信度=中"具象化：真机上它确实
   只对同分布负载是收益。
3. **在线落地条件（真机要求，非空谈）**：
   - 热表/预取知识**必须与部署负载同分布**采集（README 原话：≥ 长 trace，同分布）；
   - **不可用一条 trace 学、另一条跑**——真机已证会翻车（+10.3%）。
   - 若做不到同分布，更稳的路仍是**工作集驻留**（b12288 evict=0，85%）而非靠热度迁移。

## 五、一句话结论

**÷6.38 在线对价 = 预测式在同分布负载上成立（真机 −17.8% 背书）；跨分布会翻车（+10.3% 反亏）。**
所以"LY=预测式不可行"的担忧有了真机坐标：**同分布 OK，跨分布危险**——工程上按同分布部署即可兑现 ÷6.38 的对价，不必等"通用热度"。
