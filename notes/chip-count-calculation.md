| 指标 | RTX 3090 | 我们的目标 |

| 带宽 | 936 GB/s | ≥936 GB/s |

## 计算

### 带宽需求

```
需要芯片数 = 目标带宽 / 每芯片带宽
           = 936 / 68
           = 13.8
           ≈ 14 颗
```

### 性能验证（14 颗）

```
总带宽：14 × 68 = 952 GB/s ✅ (≥936)
总 MAC：14 × 34 = 476
总容量：14 × 16 = 224 GB
总功耗：14 × 16 = 224W ✅ (<350W)
总成本：14 × 91 = ¥1,274 ✅ (<¥5,000)
```

### 7B 推理性能

```
模型大小：14 GB (7B bf16)
每 token 数据搬运：14 GB
耗时：14 / 952 = 14.7 ms
吞吐：1000 / 14.7 = 68 tok/s ✅ (远超 30-40)
```

### 30B 推理性能

```
模型大小：60 GB (30B bf16)
每 token 数据搬运：60 GB
耗时：60 / 952 = 63.0 ms
吞吐：1000 / 63.0 = 15.9 tok/s
```

### 70B 推理性能

```
模型大小：140 GB (70B bf16)
每 token 数据搬运：140 GB
耗时：140 / 952 = 147.1 ms
吞吐：1000 / 147.1 = 6.8 tok/s
```
