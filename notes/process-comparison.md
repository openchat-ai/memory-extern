# 28nm vs 14nm 对比方案

> 2026-08-20 对比分析。

## 一、工艺参数对比

| 参数 | 28nm | 14nm FinFET | 优势方 |
|------|------|-------------|--------|
| 晶体管密度 | 8M T/mm² | **30M T/mm²** | 14nm（3.75x） |
| 最高频率 | ~1 GHz | **1.3-1.5 GHz** | 14nm |
| 漏电 | 低 | 中 | 28nm |
| 电压 | 0.9V | **0.75V** | 14nm（功耗低） |
| SRAM 密度 | 基准 | **2-3x** | 14nm |
| 模拟电路 | 容易 | 中等 | 28nm |
| PDK 成熟度 | 非常成熟 | 成熟（量产5年） | 28nm（略好） |

## 二、芯片设计对比

### 假设：115 个 bf16 MAC（修正后）

| | 28nm | 14nm |
|---|------|------|
| **MAC 阵列面积** | 115 × 0.125mm² = 14.4mm² | 115 × 0.033mm² = **3.8mm²** |
| **SRAM 2MB** | 8mm² | **3mm²** |
| **PCIe 控制器** | 5mm² | **2mm²** |
| **内存控制器** | 10mm² | **4mm²** |
| **其他（控制/IO）** | 5mm² | **2mm²** |
| **总面积** | **~42mm²** | **~15mm²** |
| **晶体管** | ~340M | ~450M |

### 14nm 面积小 3 倍，但晶体管多 30%（因为 FinFET 结构）

## 三、性能对比

| | 28nm | 14nm |
|---|------|------|
| MAC 频率 | 1 GHz | **1.4 GHz** |
| MAC 吞吐 | 115 GMAC/s | **161 GMAC/s**（+40%） |
| DDR 控制器频率 | 800 MHz | **1200 MHz** |
| DDR 带宽（理论） | 460 GB/s | **550 GB/s**（+20%） |
| 7B bf16 tok/s | ~25 | **~30**（+20%） |

## 四、成本对比

### 流片成本

| | 28nm | 14nm |
|---|------|------|
| MPW 拼片 | ¥50-150 万 | ¥100-300 万 |
| 掩膜版（全掩） | ¥500-1000 万 | ¥1000-2000 万 |
| 良率（预估） | 95% | 90% |

### 每片芯片成本

| | 28nm | 14nm |
|---|------|------|
| 晶圆尺寸 | 12 英寸 | 12 英寸 |
| 每片晶圆价格 | ~¥5000 | ~¥8000 |
| die 面积 | 42mm² | **15mm²** |
| 每片晶圆 dies | ~650 | **~2000** |
| **每片 die 成本** | **¥7.7** | **¥4.0** |

**14nm 每片芯片成本更低！**（面积小 3 倍 > 晶圆贵 1.6 倍）

## 五、PHY 兼容性

| | 28nm | 14nm |
|---|------|------|
| 芯动科技 PHY | ✅ 已量产 | ✅ 已量产 |
| 奎芯科技 PHY | ❓ 未确认 | ✅ 8nm 已验证 |
| PCIe PHY | ✅ 都支持 | ✅ 都支持 |

## 六、PCB 对比

| | 28nm | 14nm |
|---|------|------|
| 封装 | BGA | BGA |
| 引脚数 | 相同 | 相同 |
| PCB 层数 | 12-14 层 | 12-14 层 |
| 散热 | ~50W | ~40W（电压低） |

**PCB 设计基本相同，14nm 功耗更低，散热更容易。**

## 七、风险对比

| 风险 | 28nm | 14nm |
|------|------|------|
| 良率风险 | 低 | 中 |
| 设计复杂度 | 低 | 中（FinFET 特殊规则） |
| 代工排期 | 短 | 可能长 |
| IP 可用性 | 非常好 | 好 |

## 八、结论

| 维度 | 28nm | 14nm | 胜 |
|------|------|------|---|
| 面积 | 42mm² | **15mm²** | 14nm |
| 频率 | 1 GHz | **1.4 GHz** | 14nm |
| 每片成本 | ¥7.7 | **¥4.0** | 14nm |
| 散热 | 50W | **40W** | 14nm |
| MPW 费用 | **¥50-150万** | ¥100-300万 | 28nm |
| 设计难度 | **低** | 中 | 28nm |
| 模拟电路 | **容易** | 中等 | 28nm |

### 建议

**用 14nm。** 理由：
1. 芯片面积小 3 倍 → 每片成本低
2. 频率高 40% → 性能好 20%
3. 功耗低 → 散热容易
4. 中芯国际 14nm 量产 5 年，成熟可靠
5. 芯动科技 14nm PHY 已量产

**MPW 贵 100-200 万，但量产成本低 50%，值得。**
