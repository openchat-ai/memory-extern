# CONTRACT-SHIELD — FPGA/硬件外包 合同盾(个人接单落地模板)
> 状态: 市场证据已拉(2026-09-14) · 待第一张真单套用
> 一句话: **市场在买"可验收的证据链", 不是买"难"** — 甲方要的"证书"= 验收单/测试报告/STA报告/交付清单这串可回查证据。你手里的真硅台账+账实一致纪律, 正是这串证据的真身。

## 0 为什么接单先立盾不先烧板
| 甲方视角 | 你(乙方)视角 |
| --- | --- |
| 买"过关"的证据链(验收单/测试报告/著作权声明) | 卖"能回查"的证据链(真硅台账/STA报告/时序收敛) |
| 最怕: 交付的板"查无实据" | 最怕: 验收被无限拖延 / 责任被无限追索 |

**市场把"证书市场"分两半 —— 一半是骗局(毕设代做/答辩"过关"), 一半是真证据链(验收判据/测试报告)。你只做能回查的那一半。**

## 1 合同定性: 选"承揽"不是"委托"(决定生死)
| 维度 | 承揽合同(推荐) | 委托合同(高险) |
| --- | --- | --- |
| 法律依据 | 《民法典》770-787 | 《民法典》919-936 |
| 报酬依据 | 交付约定工作成果 | 处理委托事务(可按工时/里程碑) |
| 完成义务 | 承揽人须交付符合约定的成果 | 受托人只须勤勉处理, 不担成果 |
| 适用场景 | 需求明确的定制开发(FPGA/时序收敛) | 驻场/长期运维(口头"合同"高风险) |
| 风险点 | 定作人可随时解除但须赔偿(787) | 易被认定事实劳动关系 → 补社保+双倍工资 |

**避免被认定"事实劳动关系"的三条**:
1. 合同声明"本合同为民事委托/承揽关系, 构成劳动关系, 不适用《劳动合同法》"
2. 不管理乙方人员/不打卡/不排班, 指令只经乙方项目负责人下达
3. 驻场人员避免用甲方工牌/企业邮箱/内部会议

## 2 验收判据: 写死且可量化(防御甲方"无限拖延")
- **交付物 = 可验收的证据, 不是"能跑的板"本身**
  - 《需求规格说明书(HRS)》 (验收判据的起点)
  - 《测试用例清单》 + 测试报告 (功能/性能判据)
  - 《交付物清单》(源码/文档/工程文件)
- **FPGA 专业量化判据(你的主场)**:
  - "乙方交付 PnR 时序收敛报告, STA slack≥0 (以真硅上板观测为准)"
  - "PLL 在 X MHz 真锁(physically locked, 以 sentry 上板观测为准)"
- **缺陷分级(写死修复时限)**:
  | 等级 | 定义 | 修复时限 |
  | --- | --- | --- |
  | A级 | 系统无法运行/数据丢失/安全漏洞 | 〇个工作日内 |
  | B级 | 部分功能无法使用 | 〇个工作日内 |
  | C级 | 界面等非功能问题 | 下一版本 |
- **"视为验收合格"条款(防拖延)**: 甲方在验收期(〇日)内未书面提出不合格意见 → 视为验收通过
- 缺陷 = 写死《测试计划》里已列出的判据; 新需求 = 走变更控制流程(书面变更请求→协商工期/费用)

## 3 责任上限(个人接单的保命线)
- 违约赔偿上限 ≤ 合同总额的 〇%(建议 ≤ 30%~100% 内写死, 不写"无限")
- 质量瑕疵责任: 终验合格之日起 〇 年内, 之后不再担
- **"不承诺成果成败, 只承诺按验收判据交付"** — 合同写明验收判据就是你的"证书"
- 严禁: 代写/代做毕设(黑产) → 教科书级只做真验收证据

## 4 付款: 防"验收后另行约定"这种坑("视为验收合格"配套)
- 分期: 3:4:3 (启动/验收前/最终验收后) 或里程碑制
- 付款期限 ≤ 60 日 (《保障中小企业款项支付条例》: 逾期可追违约金, 个人主体也适用)
- 禁写: "验收后另行协商付款时间" (会被推迟方利用)

## 5 著作权(默认规则是坑)
- 合同不写明 → 代码著作权**默认归乙方**(开发方), 不归出资方 — 甲方往往不知道!
- 若著作权要归甲方 → 必须书面写明 + 费用含"过户价"
- 通用库/框架权属: 乙方保留, 甲方获非独占许可
- 保密条款必覆盖: 需求、接口规范、项目文档

## 6 资质 / 注册(你要的"门槛"答案)
| 层 | 门槛 | 个人能否进 |
| --- | --- | --- |
| 平台接单(第一层) | 无资质, 个人即可; 注册个体户开票 | ✔ 随时能进 |
| 企业级硬件外包(第二层) | 个体户/工作室 + 合同 + 验收证据链 | ✔ 可进 |
| 军工/政府/国企/IPO(第三层) | 保密资质/合格供方名录/GJB9001C/CMA-CNAS | ✘ 第三方授予, 个人自造不了 |

- **个人注册**: 个体工商户(登记费 0 元, 线上办 5-15 个工作日) or 一人有限公司(认缴制, 无需实缴; 但这种要在账目/资金严格区分, 否则无限连带)
