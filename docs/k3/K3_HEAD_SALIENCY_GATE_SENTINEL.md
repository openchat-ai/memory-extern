# K3 gate.weight 哨兵行结构实测（原始 K3 权重事实）

日期: 2026-09-08
数据: `/mnt/nvme/trunk/trunk.bin` + `trunk.json`（BF16 trunk, 108.8GB）
方法: 直读 gate.weight 原始 BF16 位, 统计异常指数（`exp == 0xFF` 及 `exp > 140`）

## 现象

K3 的 MoE 路由 gate 权重 `block_sparse_moe.gate.weight` 在 **MLA（Gated-MLA）层**含有一批特殊行：

| 属性 | MLA 层 (L3/7/11/15/.../92) | KDA 层 (其余 69 层) |
|---|---|---|
| `exp==0xFF` 元素总数 | **621 / 6,422,528 (0.0097%)** | **0** |
| 特殊行号 | 恒为 **0..44（45 行）** | - |
| 每行特殊元素数 | 5 ~ 23（均值 13.8） | - |
| 受影响列（mod-128 分布） | 分散（64 种余数, 573 distinct 列） | - |
| `exp > 140` 高指数元素(非0xFF) | **70,938（全落在 0..44 行内）** | 0 |
| 原始位图样 | `0xFFAC / 0xFFA8 / 0xFFBF / 0xFFC0` 等 | - |

**跨层一致性**: L3 / L31 / L47 / L92 观测到**完全相同**的行号（0-44）、元素数（621）、每行分布（5-23）、原始位图样。这不是独立权重的偶发值, 而是 trunk 中 gate 的固定结构。

**行级整体异常**: 45 个特殊行内除 621 个 `0xFF` 外, 还含 70,938 个 `exp∈(140,255)` 的高指数元素 — **这 45 行整行都是异常数据**, 非零星坏位。排除后其余 851 行 BF16 指数分布正常（主峰 exp≈115-123）。

## 邻接事实

- `e_score_correction_bias`（F32[896]）位于 off=0, `gate.weight`（BF16[896,7168]）位于 off=3584, 两者**首尾相接无 padding**（gate 末元素 exp=0x3d15 正常）→ 哨兵不是对齐填充, 属于 gate 张量真实内容。
- 哨兵行对应的 bias 值偏高（约 -0.52 ~ +0.83）, 而正常 851 行 bias 均值约 **-3.96** (std 2.03) — 哨兵行对应的是「偏正偏置」的专家。
- KDA 层 gate 完全无这类行（exp 分布干净）。

## 对显著性分析的影响（head_saliency）

- 含哨兵行的 45 行**行范数会被推到 ~1e38-1e39**, 使 MLA 层 gate 行范数 cv 虚高（假 4.39）。
- **排除哨兵行后** MLA 层 gate 行范数 cv ≈ **0.11**, 与 KDA 层 0.15 同量级 — 无跨层异质性。
- head_saliency 现逻辑（`gate_row_norms_clean`）已剔除哨兵行并上报 `n_sentinel_rows`。

## 结论

1. MLA 层 gate 前 45 行（专家 0-44）含整行异常数据（`exp==0xFF` + 高指数）, 不是有效 BF16 权重数值, 计算范数/路由统计时必须整行剔除。
2. 这是 **K3 原始 trunk 的固定结构**（KDA/MLA 打包差异）, 非本机损坏或对齐填充。
3. 专家 0-44 在 MLA 层可能有特殊语义（偏正 e_score_correction_bias）, 是否对应真实不可选专家待激活侧验证（H2 探针）。
